Chirp API Documentation

High-performance, tag-aware RichText typewriter & dialogue engine for Roblox. Built for frame-perfect grapheme rendering, multi-effect tag stacking, custom developer effect registration, and zero network overhead.

Quick Setup

-- Initialize Chirp instance
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Chirp = require(ReplicatedStorage.Chirp)

-- Register custom inline tag effect
Chirp.RegisterEffect("pulse", function(index, time)
    return math.sin(time * 8) * 3, 0
end)

local dialogue = Chirp.new(labelInstance, { Speed = 0.04, Preset = "Pop" })

-- Type dialogue line
dialogue:Type("yo <font color='#00FF88'>al</font>! <pause=0.5> welcome to <wave><pulse>chirp</pulse></wave>.")

API Reference

Chirp.new(textLabel: TextLabel, options: ChirpOptions?): ChirpInstance

Creates a new Chirp typewriter instance bound to a target TextLabel.

Methods & Static Functions

:Type(rawText: string, startTime: number?)

Parses and types out a dialogue string. Pass workspace:GetServerTimeNow() to startTime for synchronized multiplayer cutscenes.

:Skip()

Instantly completes character reveal for the current line while keeping active loop animations running.

:Stop()

Halts active typing immediately, hides continuation prompt, and disconnects render loops.

:Destroy()

Unbinds all connections, destroys prompt elements, and cleans up instance memory safely.

Chirp.RegisterEffect(name: string, callback: (index, time) -> (size, trans)) (Static)

Registers a custom inline effect tag at runtime. The callback receives index & time and returns size and transparency offsets.

Chirp.Sanitize(rawUgcText: string): string (Static)

Sanitizes user-generated string input (<, >, &) to prevent RichText XML injection attacks.

Signals (Events)

OnComplete Fires when line typing finishes
OnPause:Connect(duration) Fires when reaching <pause=X> tag
OnEventTriggered:Connect(name) Fires when reaching <event=X> tag

Options (ChirpOptions)

Property Type Default Description
Speed number 0.04 Delay per grapheme in seconds.
Preset string "Classic" Reveal style: "Classic", "Glitch", "Fade", or "Pop".
Sound Sound? nil Sound instance played per character reveal.
RandomizePitch boolean true Enables random pitch shifting on sound play.
PitchRange Vector2 (0.95, 1.05) Min/max pitch playback scale.
Caret string? "|" Inline cursor character shown while typing.
ShowPrompt boolean true Auto-spawns continuation prompt on line completion.

Custom Tags & Commands

Tag Syntax Type Behavior
<shake>...</shake> Effect Applies real-time character size jitter.
<wave>...</wave> Effect Animates text in a smooth optical subpixel wave.
<customTag> Effect Registered via Chirp.RegisterEffect(name, fn).
<pause=X> Command Halts typewriter execution for X seconds.
<speed=X> Command Overrides typewriter character delay to X.
<event=X> Command Triggers OnEventTriggered signal with payload X.
