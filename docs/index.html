60 FPS Grapheme Engine

Uses MaxVisibleGraphemes & RenderStepped. Unclosed RichText tags are automatically hidden during reveal without leaking raw XML.

🌀

Stacked Math Effects

Nest multiple custom inline animation tags simultaneously like <shake> and <wave> without visual glitches.

🛡️

Zero-Packet Networking

Server sends 1 single payload to client. Typing runs completely locally with 0 network bandwidth and memory-safe connection guards.

Quick Usage Example

local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Chirp = require(ReplicatedStorage:WaitForChild("Chirp"))

local dialogue = Chirp.new(label, {
    Speed = 0.04,
    Preset = "Pop",
    ShowPrompt = true,
})

dialogue:Type("yo <font color='#00FF88'>al</font>! <pause=0.5> welcome to <shake><wave>chirp engine</wave></shake>.")
